| 项目 | 内容 |
|---|---|
| 文档版本 | v1.0 |
| 编写日期 | 2026-09-03 |

---

## 一、背景与目标

### 1.1 背景

催收系统需要通过 AI 智能语音外呼方式触达逾期客户。目前已接入两家 AI 服务商：**AI Rudder** 和 **Dyna**。需要在催收系统后台实现消息中心模块，管理 AI 服务商、催收话术模板、发送任务及发送记录。

### 1.2 目标

- 运营人员可在后台查看服务商状态、管理 AI 催收话术模板、创建和管理 AI 发送任务、查看发送结果并对失败消息进行补发。
- 一期仅实现 AI 智能催收场景，其余渠道（SMS、Email、RCS、IVR、WABA、APP Push）后续迭代。

---

## 二、系统架构

### 2.1 导航结构

消息中心位于催收系统左侧导航栏的 **业务配置** 目录下：

```
催收系统
└── 业务配置
    ├── 组织架构
    ├── 逾期阶段
    ├── 自动分案
    ├── 委外催收配置
    ├── 减免规则
    ├── 排班管理
    └── 消息中心            ← 新增
        ├── 服务商管理
        ├── 模板管理
        │   └── AI 智能      ← 一期仅此一项
        ├── 发送任务
        │   └── AI 智能      ← 一期仅此一项
        └── 发送记录
```

### 2.2 页面交互

- 移除顶部 Tab 切换，改为左侧导航栏子目录直接渲染对应页面。
- 每个页面独立，支持按条件查询。

## 三、功能模块

### 3.1 服务商管理

#### 3.1.1 功能定位

纯展示页面，运营人员查看各渠道服务商列表及启用状态。**不支持新增、编辑、启用/禁用操作**，服务商的接入和配置由技术团队在服务端完成。

#### 3.1.2 页面布局

| 区域 | 内容 |
|---|---|
| 标题 | 服务商管理 |
| 说明文字 | "查看各渠道服务商列表及启用状态。新增或调整服务商请联系技术支持。" |
| 统计卡片 | 已开启服务商数量 / 已关闭服务商数量 |
| 搜索栏 | 按服务商名称、ID、类型搜索 |
| 表格 | 见下表 |

#### 3.1.3 表格字段

| 列名 | 说明 |
|---|---|
| 服务商名称 | 显示服务商名称 + 服务商ID |
| 类型 | SMS / Email / RCS / IVR / AI / WABA / APP Push（用彩色标签区分） |
| 绑定模板 | 该服务商绑定的模板名称列表 |
| 状态 | 已开启 / 已关闭 |

#### 3.1.4 一期数据

AI 类型的服务商已接入两家：

| ID | 名称 | 类型 | 状态 |
|---|---|---|---|
| SP008 | AI Rudder | AI | 已开启 |
| SP009 | Dyna | AI | 已开启 |

---

### 3.2 模板管理 — AI 智能

#### 3.2.1 功能定位

管理 AI 催收话术模板，支持增删改查。AI 模板必须绑定服务商（AI Rudder 或 Dyna），并配置策略 ID（策略 ID 由服务商后台配置后回填）。

#### 3.2.2 统计卡片

| 卡片 | 说明 |
|---|---|
| 已启用 | 状态为"已启用"的模板数量 |
| 已停用 | 状态为"已停用"的模板数量 |
| 模板总数 | 全部模板数量 |

#### 3.2.3 查询栏

| 查询条件 | 类型 |
|---|---|
| 模板名称/ID | 文本输入 |
| 状态 | 下拉选择（已启用 / 已停用） |
| 操作 | 查询按钮 + 重置按钮 |

#### 3.2.4 表格字段

| 列名 | 说明 |
|---|---|
| 模板名称 | 模板名称 + 模板ID |
| 服务商 | 绑定的服务商名称（AI Rudder / Dyna） |
| 策略ID | 服务商后台配置的策略标识 |
| 状态 | 已启用 / 已停用 |
| 更新时间 | 最后编辑时间 |
| 操作 | 详情 / 编辑 / 启用·停用 / 删除 |

#### 3.2.5 新建/编辑表单

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 模板名称 | 文本输入 | 是 | 自定义模板名称，便于运营识别 |
| 服务商 | 下拉选择 | 是 | 选项：AI Rudder、Dyna |
| 策略ID | 文本输入 | 是 | 在服务商后台创建策略后获得的 ID |

#### 3.2.6 业务规则

- 删除模板前弹出确认弹窗。
- 停用模板后，已有任务仍可正常执行，但不能被新任务引用。
- 服务商选项来源于服务商管理中的 AI 类型且状态为"已开启"的服务商。

---

### 3.3 发送任务 — AI 智能

#### 3.3.1 功能定位

创建和管理 AI 发送任务。支持按条件查询、新建任务、启用/关闭任务、复制任务、查看任务详情。

#### 3.3.2 统计卡片

| 卡片 | 说明 |
|---|---|
| 已启用 | 状态为"启用"的任务数量 |
| 已关闭 | 状态为"关闭"的任务数量 |
| 任务总数 | 全部任务数量 |

#### 3.3.3 查询栏

| 查询条件 | 类型 |
|---|---|
| 任务名称/ID | 文本输入 |
| 发送状态 | 下拉选择（启用 / 关闭） |
| 发送时间范围 | 日期范围选择器 |
| 操作 | 查询按钮 + 重置按钮 |

#### 3.3.4 表格字段

| 列名 | 说明 |
|---|---|
| 任务名称 | 任务名称 + 任务ID |
| 模板 | 选中的 AI 模板名称（多选用顿号分隔） |
| 客群 | 选中的客群名称（多选用 + 连接）+ 总人数 |
| 服务商 | 绑定的服务商名称 |
| 发送时间 | 任务创建/定时发送时间 |
| AI 配置 | 执行日期 + 产品标签 |
| 状态 | 启用 / 关闭 |
| 操作 | 详情 / 复制 / 启用·关闭 |

#### 3.3.5 新建任务表单

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 任务名称 | 文本输入 | 否 | 不填则自动生成（客群名称-AI） |
| 发送模板 | 多选下拉 | 是 | 支持多选 AI 模板，选中多个策略话术轮换使用 |
| 执行日期 | 单选 Radio | 是 | 工作日 / 非工作日 |
| 产品 | 多选下拉 | 是 | 选项：CL01、CL02、CL03、CL04、CL05、CL06、CL07、CL08 |
| 定时发送 | 日期时间选择 | 否 | 不选则立即发送 |
| 选择客群 | 多选下拉 | 是 | 客群来源：大数据平台输出。多选时人数累加 |

#### 3.3.6 高级配置（可折叠）

| 字段 | 说明 |
|---|---|
| 多服务商分配 | **服务商跟随已选模板**：仅展示已选模板绑定的服务商（去重）。未选模板时提示"请先选择模板"。首选模板绑定的服务商默认比例 100%，其余 0% |
| 比例校验 | 所有服务商比例之和不能超过100%，超过则标红提示并阻止提交 |
| 单服务商 | 若所选模板仅绑定一个服务商，提示"当前仅绑定一个服务商，无需分配比例" |

#### 3.3.7 任务操作

| 操作 | 适用状态 | 说明 |
|---|---|---|
| 详情 | 所有 | 弹窗展示任务完整信息 + AI 配置 |
| 复制 | 所有 | 打开新建弹窗并预填原任务配置（名称加"-副本"），确认后创建为新任务 |
| 启用/关闭 | 所有 | 弹出确认弹窗，确认后切换任务启用状态 |

#### 3.3.8 任务状态流转

```
启用 ──关闭──→ 关闭
关闭 ──启用──→ 启用
```

> 说明：一期简化为启用/关闭两态，不再跟踪发送进度与运行态。

### 3.4 发送记录

#### 3.4.1 功能定位

查看历史发送记录，支持按条件查询，对发送失败的消息进行补发。**不展示发送进度，不支持继续发送功能。**

#### 3.4.2 查询栏

| 查询条件 | 类型 |
|---|---|
| 发送方式 | 下拉选择（短信 SMS / 邮件 Email / 富媒体 RCS / 语音 IVR / AI智能 / WhatsApp / APP Push），默认全部 |
| 批次号/内容 | 文本输入 |
| 发送时间范围 | 日期范围选择器 |
| 操作 | 搜索按钮 + 重置按钮 |

#### 3.4.3 表格字段

| 列名 | 说明 |
|---|---|
| 发送时间 | 记录创建时间 |
| 触发方式 | 手动 / 定时 |
| 发送方式 | 短信 SMS / 邮件 Email / 富媒体 RCS / 语音 IVR / AI智能 / WhatsApp / APP Push（彩色标签） |
| 服务商 | 绑定的服务商名称（如 AI Rudder / Dyna） |
| 内容 | 模板名称或发送内容摘要 |
| 批次号 | 批次唯一标识 |
| 结果 | 全部成功 / 部分失败 / 全部失败 |
| 发送数 | 成功发送数量 |
| 失败数 | 发送失败数量 |
| 成功率 | 百分比 |
| 状态 | 已完成 / 失败 |
| 操作 | 成功记录"无需补发"；失败记录显示"补发"按钮 |

#### 3.4.4 补发逻辑

- 仅对有失败消息的记录显示"补发"按钮。
- 点击补发后，重新发送失败部分的消息。
- 补发成功后更新成功/失败计数和状态。
- 全部补发成功后状态自动变为"已完成"。
- 支持多次补发，累计补发次数。

## 四、数据来源说明

### 4.1 客群数据

客群由 **大数据平台** 输出，催收系统不管理客群。创建任务时直接从大数据平台返回的客群列表中选择。

### 4.2 服务商配置

服务商的接入、API 配置、启停由技术团队在服务端完成。前端仅做展示。

### 4.3 AI 策略

AI 催收话术策略在服务商后台（AI Rudder / Dyna 后台）创建和配置，获得策略 ID 后在模板管理中录入绑定。

## 七、验收标准

1. 服务商管理页面可查看 AI Rudder 和 Dyna 两家 AI 服务商信息，无编辑/启停操作。
2. AI 模板管理支持新增、编辑、删除、启用/停用 AI 模板，模板需绑定服务商和策略 ID。
3. AI 发送任务支持：
   - 多选 AI 模板
   - 选择执行日期（工作日/非工作日/每天）
   - 多选产品（CL01-CL08）
   - 多选客群
   - 定时/立即发送
   - 多服务商比例分配（总额不超过 100%）
   - 任务启用/关闭切换（不再跟踪发送进度）
4. 任务列表支持按名称/ID、状态（启用/关闭）、时间范围查询。
5. 任务支持启用/关闭、复制操作。
6. 发送记录支持按发送方式（渠道）、批次号/内容、时间范围查询，支持补发失败消息。
